# RetailSense – Online Retail Recommendation System

## About
RetailSense is a machine-learning-based fashion recommendation web application that helps users search fashion products and discover similar items from a product catalogue.

## Features
- Search fashion products by keywords.
- Recommend similar products using machine learning.
- Display product images and details.
- View product category analytics.

## Technologies Used
- **Frontend:** React, Vite, CSS
- **Backend:** Python, Flask
- **Machine Learning:** Scikit-learn, TF-IDF
- **Data Processing:** Pandas, NumPy
- **Deployment:** Render

## How to Run

**Backend**
```bash
cd backend
pip install -r requirements.txt
python app.py
```

**Frontend**
```bash
cd frontend
npm install
npm run dev
```
